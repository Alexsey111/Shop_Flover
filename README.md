# Shop_Flover — онлайн-магазин цветов на Django

Дипломный проект по итогам обучения на платформе zerocoder: витрина цветочного магазина
с корзиной, оформлением заказа, отзывами и телеграм-ботом для покупателя.

## Что умеет

- Каталог с категориями и фильтром по цене (`products/views.py: product_list`).
- Карточка товара и отзывы с оценкой от 1 до 5; оценка проверяется моделью `Review.clean`.
- Корзина: добавление, увеличение количества, уменьшение и удаление позиции, пересчёт суммы
  (`Cart.update_total_price`).
- Оформление заказа: выбор доставки и оплаты, создание `Order` и `OrderItem`, очистка корзины.
- Предпросмотр заказа и подтверждение: статус меняется на «выполнен», выбранные доставка
  и оплата сохраняются.
- Заказы видны только их владельцу (`order_detail` и `confirm_order` фильтруют по `user`).
- Телеграм-бот (`telegram_bot`): привязка чата к аккаунту, подтверждение заказа сообщением,
  отчёт по продажам по команде из бота.
- Регистрация и вход: кастомная модель `users.CustomUser` с полем `chat_id`.

## Стек

Python 3.13, Django 5.1, SQLite, Bootstrap 5, python-telegram-bot 21.6.
Полный список зафиксированных версий — `requirements.txt` (UTF-8, 150 пакетов).

## Структура

    flower_project/     настройки, корневые urls, статика
    products/           каталог, корзина, заказы, отзывы, модели и тесты
    users/              кастомный пользователь, регистрация
    telegram_bot/       бот, уведомления о заказе, management-команда run_bot
    templates/          шаблоны products/ и registration/
    populate_products.py  наполнение базы демо-товарами

## Запуск

    python -m venv .venv
    .venv\Scripts\activate            # Windows
    pip install -r requirements.txt
    python manage.py migrate
    python populate_products.py       # демо-товары и категории
    python manage.py runserver

Сайт откроется на http://127.0.0.1:8000/.

### Телеграм-бот

Токен в код не вписан: он берётся из переменной окружения `TELEGRAM_BOT_TOKEN`,
без неё запуск падает с понятной ошибкой.

    set TELEGRAM_BOT_TOKEN=<токен от @BotFather>      :: Windows
    export TELEGRAM_BOT_TOKEN=<токен>                 # Linux/macOS
    python manage.py run_bot

Бот запускается отдельным процессом, рядом с `runserver`.

## Тесты

    python manage.py test

Покрыто: каталог и карточка товара, доступ к корзине только после входа, увеличение
и уменьшение количества, пересчёт суммы, оформление заказа с очисткой корзины, отказ
при неполной форме, подтверждение заказа без корзины, сохранение доставки и оплаты при
подтверждении, запрет на чужой заказ, сохранение отзыва и отказ при оценке вне 1–5.

## Переменные окружения

    DJANGO_SECRET_KEY   секретный ключ; по умолчанию стоит dev-значение из репозитория
    DJANGO_DEBUG        «1» включает отладочный режим (по умолчанию включён)
    TELEGRAM_BOT_TOKEN  токен бота, обязателен для запуска бота

В продакшене задайте `DJANGO_SECRET_KEY`, выключите `DJANGO_DEBUG` и заполните `ALLOWED_HOSTS`.

## Ограничения

- Оплата не подключена: выбор способа оплаты сохраняется в заказе, платёжный шлюз не вызывается.
- SQLite: для демонстрации и диплома достаточно, для нагрузки нужен PostgreSQL.
- Доставка считается по фиксированному списку способов, интеграции со службами нет.
